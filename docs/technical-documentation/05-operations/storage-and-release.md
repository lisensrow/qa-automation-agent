## Локальный inference и полный источник регресса

Полные два цикла сохранены офлайн: Windows21кейс/159шагов, Astra19/142, всего40/301. Оригинальные XML хранятся приватно: в исторических примерах есть учётные данные. В searchable копиях их значения замаскированы; сохранены полные действия, тестовые данные, expected, редакции и hashes. Источник не является разрешением выполнить удаление идентичности, изменение защиты/X-access или переустановку. Перечень и подготовка источника не засчитываются в прохождение регресса.

Для игры на основной карте существующий Ollama закреплён за Quadro RTX4000 по UUID только в окружении его процесса. Глобальные CUDA-переменные не меняются. Исходный ярлык автозапуска сохранён перед заменой на отдельный скрытый launcher; rollback — восстановление этого ярлыка. Модель qwen3:14b не заменялась. На контексте24576 измерено примерно6выходных токенов/с при частичном CPU/GPU размещении; скорость конкретного кейса зависит также от входа и инструментов. Эти данные — операторский benchmark, не приёмка агента.

Уменьшение контекста требует одинаковых заданий/эталонов, проверки отсутствия потери входа и отдельной оценки ошибок. Нельзя улучшать скорость молчаливым удалением policy, ожидаемого результата, источника или actual. Конечный набор проверок не гарантирует равного качества на произвольной задаче. Полный регресс, автономность модели и текущее состояние рабочих столов остаются отдельными критериями.

## Добавочное обновление памяти

До schema migration сверить clean source state и сохранить согласованную backup product DB. Добавлять только knowledge_v1_* таблицы. Сравнить schema/content fingerprints прежних таблиц и документного индекса до/после. Не выполнять backfill/переклассификацию старых verified facts в этом этапе.

Runtime ingestion записывает candidates/manifest/support/event транзакцией. При ошибке нет частично принятого event; exact retry не дублирует запись. Восстановление не должно возвращать всю БД из backup поверх новых чужих изменений без анализа и разрешения.

## Риски

Нехватка диска может блокировать очереди/запросы продукта. Диагностика должна отличать infrastructure от session expiration и дефекта функции. Очистка журналов/данных требует отдельного разрешения и проверяемого recoverable scope; защитные thresholds не понижаются для продолжения теста.

Общие concurrent Job RMW и unknown legacy/autosave paths остаются отдельными ограничениями. SSH host-key trust текущего MVP требует усиления перед эксплуатацией вне лаборатории. Новая source policy не является заменой authentication/RBAC.

Для shared документации передавать папку этого пакета или утверждённые Git docs, не полный checkout с Jobs/secrets/backups. Документы пакета сами по себе не выполняют команды и не предоставляют доступ к стенду.
