# Граница приёмки установочного сценария

Полученный дистрибутив, его правильная версия и контрольная сумма не доказывают
установку. Скачиваемый для конкретной конфигурации пакет может отличаться от
исходного файла поставки; такие пакеты нельзя публиковать или включать в Git.

При замене ядра установщик способен остановить собственную службу агента.
Исполнитель должен переживать это отключение, сохранять независимый результат
и предусматривать восстановление. Подтверждение отправки задачи недостаточно.

Документированный механизм доставки файла через UC необходимо отдельно связать
с точной тестовой КЕ, существующим журналом, запретом повторной отправки и
проверкой полученного файла. Схема API не заменяет наблюдение фактического
контракта загрузки и результата доставки.

Список файлов архива не равен дереву после установки: часть данных создаётся
при запуске, часть может сохраняться от предыдущей версии. Сохранённые файлы
также не доказывают чистую установку. Нужны полные исходные шаги, заранее
закреплённые ожидаемые результаты, свежие наблюдения, проверка Tray и
восстановление исходного рабочего состояния тестовых КЕ.

Текущий этап — операторская подготовка, не новый полностью пройденный кейс и
не подтверждение самостоятельного установочного навыка локальной модели.
