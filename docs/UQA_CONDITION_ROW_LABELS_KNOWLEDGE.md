## Точный переход между поверхностями

Лист дерева Endpoint → OS name имеет короткую подпись OS name. После успешного drag в группе And соответствующая строка имеет квалифицированную подпись Endpoint.OS name. Общие Archived и CI class сохраняют короткие подписи. Оператор, значение и Aggregation type — отдельные колонки. Подпись строки не является wire-именем JSON-поля: нельзя превращать Endpoint.OS name в backend field без отдельного источника.

Первый отказ tree_row_cell_unavailable означал, что UQA искала строку по короткому имени дерева. Он не доказывал провал drag или отсутствие контрола. Гипотеза о пустой структурной колонке была проверена и снята; экспериментальное изменение общего поиска ячеек не должно оставаться в production как исправление этого отказа.

## Рецепт проверки

Доверенный профиль задаёт source=OS name для дерева и отдельный row_label=Endpoint.OS name для строки. Модель не придумывает UI mapping. Оба имени ищутся строго и проверяются в соответствующей поверхности; неоднозначность/уже существующая строка/смена контекста/частичная ошибка запрещают автоматический повтор. Итоговый readback шести ячеек должен использовать row_label, а не имя дерева. Совпадение подписи не доказывает saved AST или состав коллекции.

Старые прогоны остаются BLOCKED; новый полный критерий проверяется новым Job после изменения профиля. Старый источник логики/дерева сохраняется отдельно. При изменении сборки mapping и его применимость перепроверяются, а не объявляются вечными.
